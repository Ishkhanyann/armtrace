# ArmTrace · Ցուցադրության ուղեցույց

## Սկիզբ

Գործարկեք `start-armtrace.cmd` կամ տերմինալում՝ `npm ci`, ապա `npm run dev`։ Բացեք նշված localhost հասցեն։

Կողային ընտրացանկի «Վերականգնել սցենարները» կոճակը վերականգնում է բոլոր չորս օրինակները։ Այն նախ հարցնում է հաստատում։ Փոփոխությունները պահվում են միայն այս դիտարկիչում։

## 1. Հայաստան → Վրաստան · սովորական առաքում

1. Ընտրեք «Արտադրող» դերը և «Արեգ Տեքստիլ» կազմակերպությունը։
2. Սեղմեք `Connect Wallet`, ապա «Միացնել փորձնական դրամապանակը»։
3. «Փոխանցումներ» բաժնում ընտրեք `AT-2026-001`։
4. Սեղմեք «Ստորագրել և փոխանցել» և հաստատեք ստորագրությունը։
5. Ցույց տվեք, որ առաջին ստորագրությունից հետո պատասխանատուն չի փոխվել։
6. Անցեք ստացողի միջավայրին, կրկին միացրեք դրամապանակը և սեղմեք `Confirm Custody`։
7. Երկրորդ ստորագրությունից հետո կարգավիճակը դառնում է «Ճանապարհին», իսկ քարտեզի վրա ավելանում է հաջորդ կանգառը։
8. Նույն ձևով շարունակեք հաջորդ մասնակիցների փոխանցումները մինչև «Առաքված է» վիճակը։

Սխալ գործարքը ցուցադրելու համար ստորագրման պատուհանում բացեք «Ցուցադրության կարգավորում» և ընտրեք `Fail / Reverted`։ Պատասխանատուն ու հաշվեկշիռը չեն փոխվի։

## 2. Վրաստան → Հայաստան · մաքսային սպասում

1. Ընտրեք «Վերահսկող» դերը և միացրեք դրամապանակը։
2. «Փաստաթղթեր» բաժնում ընտրեք `AT-2026-002`։
3. Ցույց տվեք, որ շարունակելու կոճակն անջատված է։
4. Ներբեռնեք ցուցադրական բնօրինակը, ապա վերբեռնեք նույն ֆայլը։
5. Հաստատեք ֆայլի հեշի գրանցման գործարքը։
6. Գրեք լուծման նկարագրությունը և սեղմեք «Թույլատրել շարունակել երթուղին»։
7. Խմբաքանակը կրկին կարող է փոխանցվել։ Մաքսային խնդրի պատմությունը պահպանվում է։

## 3. Իտալիա → Հայաստան · փաստաթղթի անհամապատասխանություն

1. Նույն վերահսկողի միջավայրում ընտրեք `AT-2026-003`։
2. Ցույց տվեք նախորդ՝ չհամապատասխանող տարբերակը։
3. Ներբեռնեք և վերբեռնեք բնօրինակը, հաստատեք գործարքը։
4. Ցույց տվեք երկու տարբերակները․ սխալը չի ջնջվել։
5. Նկարագրեք ստուգման արդյունքը և փակեք խնդիրը։

Լրացուցիչ փորձի համար փոխեք ներբեռնված ֆայլի մեկ տառը և վերբեռնեք։ Իրական SHA-256 հաշվարկը կգտնի անհամապատասխանությունը։

## 4. Հայաստան → Գերմանիա · վնասված փաթեթավորում

1. Վերահսկողի «Փաստաթղթեր» բաժնում ընտրեք `AT-2026-004`։
2. Գրանցեք, օրինակ, «Վերափաթեթավորվել է և ստուգվել պահեստում» և փակեք խնդիրը։
3. Անցեք «Լոգիստիկ օպերատոր» → `EuroLine Logistics`։
4. «Փոխանցումներ» բաժնում սկսեք նոր փոխանցում։
5. Անցեք `Berlin Depot` ստացողին և միացրեք նրա դրամապանակը։
6. Ցանկության դեպքում մերժեք ընդունումը՝ նշելով պատճառը։ Պատասխանատուն կմնա `EuroLine Logistics`-ը։
7. Կամ հաստատեք ընդունումը՝ առաքումն ավարտելու համար։

## Արտադրողի նոր խմբաքանակը և QR կոդը

Արտադրողի դերում միացրեք դրամապանակը, բացեք «Նոր խմբաքանակ», լրացրեք ապրանքի տվյալները և գրանցեք։ Խմբաքանակների աղյուսակում բացեք նրա QR կոդը։ Այն կարելի է ներբեռնել PNG ձևաչափով կամ բացել հանրային անձնագիրը։

«Սկանավորել QR» պատուհանում հասանելի են տեսախցիկը, նկարի ընտրությունը և Batch ID-ի ձեռքով մուտքագրումը։ Localhost հասցեով QR-ը նախատեսված է նույն համակարգչում փորձարկելու համար։

## Սպառողի էջը

Բացեք QR-ի հղումը կամ ընտրեք «Սպառող» դերը։ Այստեղ ներկայացվում են միայն հագուստի հատկությունները, արտադրողը, ծագումը, առաքման կարգավիճակն ու պարզ երթուղին։ Ներքին փաստաթղթերը և Web3-ի տեխնիկական քայլերը չեն ցուցադրվում։

## Կարևոր սահմանում

Սա առաջին փուլի ուսումնական սիմուլյացիա է։ Իրական բլոկչեյն գործարքներ, NFT թողարկում, կենդանի GPS կամ մաքսային համակարգի հետ կապ չեն կատարվում։
